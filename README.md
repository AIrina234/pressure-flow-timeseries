# pressure-and-flow-analysis
# Анализ временных рядов давления и расхода

Код реализован на Python.

Используемые библиотеки:
numpy
pandas
matplotlib
scipy
statsmodels
seaborn
openpyxl

Исходные данные содержатся в файле `p_and_q_data.xlsx`:
- Лист 0 – давление (P), 1 измерение каждые 4 секунды (~1000 точек).
- Лист 1 – расход (Q), 1 измерение каждые 2 часа (~500 точек).

# Задачи
**Для давления:**
   - Построить график и автокорреляционную функцию (ACF).
   - Проверить стационарность визуально и с помощью критерия Дики–Фуллера.
   - Удалить тренд двумя методами (МНК и разности) и выбрать лучший.
   - Построить модель AR(p), подобрать порядок, оценить коэффициенты.
   - Сделать прогноз на 10 минут.

**Для расхода:**
   - Построить график и ACF, выявить сезонность.
   - Оценить период сезонности.
   - Удалить тренд с помощью последовательных разностей.
   - Сравнить четыре метода удаления сезонности (ряд Фурье, индикаторные переменные, средние по часам, сезонные разности).
   - Выбрать лучший метод по дисперсии остатков и ACF.

# Используемые методы
ACF, PACF, критерий Дики–Фуллера (ADF), МНК, метод разностей, ряд Фурье, индикаторные переменные, средние по часам, сезонные разности, t-критерий, прогноз по модели AR.

# Результаты
**Давление**: исходный ряд нестационарен; удаление тренда методом разностей даёт лучший результат (распределение остатков, затухание ACF). Выбран порядок AR(6). Построен прогноз на 10 минут.

**Расход**: выявлена сезонность с периодом 12 лагов (24 часа). Среди методов удаления сезонности лучшими оказались индикаторные переменные и средние по часам (в данном случае эти методы эквивалентны - коэффициенты при индикаторах равны соответствующим средним значениям) - у них наименьшая дисперсия остатков и ACF без значимых пиков.
